# Spec Template

## Goal

- What are we changing?
- Why does it matter?

## Scope

- What is included?
- What is intentionally excluded?

## Constraints

- Stack or architectural constraints
- Compatibility or operational constraints

## Acceptance Criteria

- Observable behavior that must be true when done

## Verification

- Commands to run
- Manual checks if needed

## Notes

- Open questions, tradeoffs, or follow-up work
